# ZERO-INBOUND-001 — GitHub CI audit experiment

This is the minimum publication artifact for the frozen ZERO-INBOUND-001
hypothesis. It does not claim demand, revenue, customers, or an external
installation.

## External run

An independent operator may fork the published repository and manually run
the `ZERO-INBOUND-001 agent-runtime audit` workflow. The workflow installs the
package, runs the existing audit CLI against the privacy-safe fixture, verifies
the output, and uploads a receipt artifact.

No telemetry, outreach, payment, secret collection, or automatic follow-up is
used. Repository views, stars, clones, downloads, and runs controlled by OMEGA
or its owner are non-signals.

## REAL evidence rule

The experiment reaches its frozen threshold only when one independently
initiated external installation attempt produces all fields required by
`evidence-contract.json`. The receipt must be bound to the published commit and
workflow/result hashes and must carry verifiable external provenance. A
successful workflow by itself is technical evidence, not qualified demand.

The exposure window begins only after an externally visible publication has
been independently verified. It lasts 30 calendar days. Zero qualifying
receipts at the end of that window is preserved as rejection evidence.

## Kill and rollback

The owner may disable the workflow and archive or remove the publication at
any time. Stop immediately if private data is exposed, provenance cannot be
verified, the frozen files drift, or the experiment requires spend, outreach,
or an unauthorized identity. Historical evidence must not be rewritten.
