# Permanent Project Rules

- The repository is the source of truth.
- Existing verified implementation beats conversational memory.
- Never restart from V0.1.
- Never fabricate test results or version completion.
- Never overwrite working architecture without recorded justification.
- Never silently discard project or user data.
- No milestone bump without verified implementation and Definition of Done.
- Keep changes recoverable through Git where available.
- Record decisions that materially affect future work.
- Protect security-sensitive and destructive actions with appropriate safeguards.
- Keep experimental features visibly separate from stable Core.
- A dirty working tree is context to preserve, not permission to erase work.
