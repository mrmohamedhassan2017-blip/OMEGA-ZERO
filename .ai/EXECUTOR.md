# AI Executor Contract

1. Read `PROJECT_STATE.md` first.
2. Read `NEXT_TASK.md`.
3. Inspect the existing implementation before editing.
4. Verify the current version from the repository.
5. Run relevant tests before major changes when practical.
6. Continue from the current verified state.
7. Never recreate completed milestones.
8. Never silently change the canonical project path.
9. Prefer modifying existing working components over duplicating them.
10. Implement before claiming progress.
11. Run tests after changes.
12. Never mark a milestone complete if its Definition of Done fails.
13. Record failures honestly.
14. Update `PROJECT_STATE.md` and `CHANGELOG.md` after verified work.
15. Update `NEXT_TASK.md` after milestone completion.
16. Preserve backward compatibility where reasonable.
17. Never delete or weaken failing tests merely to obtain green status.
18. Distinguish implemented, tested, experimental, and planned functionality.

Entry sequence: Inspect → Recover Context → Verify → Continue → Test → Record State.
