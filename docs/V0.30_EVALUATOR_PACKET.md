# V0.30 Independent Evaluator Packet

This packet is ready for real external evaluators. OMEGA must not fill it in on their behalf.

## Roles and separation

1. The case owner exports a real problem bundle and keeps the private reveal inaccessible to OMEGA and the evaluator runner.
2. Each independent evaluator reviews the problem before seeing OMEGA's prediction, chooses an expected attack order, declares conflicts, and supplies a stable pseudonymous `evaluator_ref`.
3. The operator runs `eval-prepare`; only the public case goes to the prediction step.
4. After the prediction file is fixed, the operator runs `eval-score` with the original private reveal.
5. Two or more records with genuinely independent evaluator references are aggregated with `eval-aggregate`.

## Required evaluator observations

For each session, record outside the committed reveal:

- evaluator reference and conflict-of-interest statement;
- whether Facts, Assumptions, Constraints, Unknowns, and relationship direction were understandable;
- time or friction encountered during onboarding, ranking, reveal, and review;
- whether WHY, BREAK IT, PROVE IT, or WHAT IF changed the evaluator's intended next action;
- one bounded recommendation tied to an observed difficulty;
- later decision outcome when available.

Do not include credentials, private reveal content, or claims of independence that the evaluator did not supply.

## Evidence gate

V0.30 cannot complete until at least two independently supplied blinded sessions exist. `eval-aggregate` reports `evidence_gate.satisfied`; repeated sessions from one evaluator do not satisfy it. Agreement metrics measure ranking agreement only and do not prove user benefit.

## Commands

```powershell
python -m omega.cli export <problem-id> --out evaluator-problem.json
python -m omega.cli eval-prepare evaluator-problem.json evaluator-labels.json --public-out public.json --reveal-out private-reveal.json
python -m omega.cli eval-run public.json --out prediction.json
python -m omega.cli --db data/omega.db eval-score public.json prediction.json private-reveal.json --out result.json
python -m omega.cli eval-aggregate result-evaluator-1.json result-evaluator-2.json
```

Store the private reveal separately until the prediction is fixed. Never send it with the public case.
