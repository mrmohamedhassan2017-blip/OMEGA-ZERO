# THE KEY

Every door in OMEGA must have a key: a concrete question, a falsifiable test, a recorded result, and a next change.

For the current Core:

- The door is **useful prioritization**.
- The key is **blind evaluation against an explicit expected order**.
- The observed result is currently partial (`top1 = false`, pairwise agreement `0.5`) on the internal self-case.
- The next change must improve ranking and then rerun the same case.

No result is promoted to external truth merely because it was generated by OMEGA. Internal evidence remains internal until an independent evaluator supplies a separately controlled case and outcome.
