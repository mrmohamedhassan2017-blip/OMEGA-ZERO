# Scientific Learning Bootstrap

OMEGA's scientific learning path is a bounded consumer of the existing runtime. It does not schedule work, own processes, or grant authority. Task ownership and recovery remain in `omega.task_continuity`; execution acceptance remains Host-verified.

The durable campaign is `learning-bootstrap-001`. It stores hash-sealed knowledge objects, source provenance, prerequisite edges, deterministic assessments, retained errors, and fail-closed contradictions beneath `.omega/zero/scientific_learning/`.

Knowledge progresses through explicit states. The first campaign may reach `PROBLEM_TESTED` or `APPLIED`; it cannot reach `TRUSTED`. Trust requires later independent replication and fresh evidence.

The first curriculum covers mathematics, binary/hex and fixed-width integers, CPU/register/memory/instruction basics, source-to-process execution, Python, algorithms/testing, defensive cybersecurity authority concepts, electricity, Ohm's law, Kirchhoff's laws, and digital logic.

Cybersecurity is always `DEFENSIVE_AUTHORIZED_ONLY`. Learning grants no external-write, financial, physical-control, credential, or target-testing authority.

Commands:

```text
python -m omega.cli scientific-learning-run
python -m omega.cli scientific-learning-status
```

The first application is deliberately `TEST_ONLY`: it compares naive Python hexadecimal rendering with fixed-width normalization of signed and unsigned Windows status `0xC000013A`. A pass creates only a `CAPABILITY_CANDIDATE`; production routing remains unchanged.

The first bounded continuation campaign is `probability-statistics-001`. It covers 14 ordered units from probability foundations through measurement uncertainty and noisy benchmarks. Each unit requires source provenance, active recall, a novel problem, and limitation/error analysis.

```text
python -m omega.cli probability-statistics-run
python -m omega.cli probability-statistics-status
```

Its TEST_ONLY application freezes the question, metric, sample/stopping rule, and threshold before reading the existing Claude shadow benchmark. The first result is intentionally not overclaimed: 3/3 observed successes have a 95% Wilson interval of `[0.438503, 1.0]`, which is `INSUFFICIENT_EVIDENCE` under the frozen minimum of 10 observations and 0.80 lower-confidence-bound requirement. The resulting capability remains SHADOW-only pending fresh replication.
